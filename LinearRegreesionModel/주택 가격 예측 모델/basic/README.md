# 주택 가격 예측 모델(basic)
- 기본 개념을 이용하여 모델 구현

## 데이터
본 프로젝트에서는 주택 가격 예측을 위해 Kaggle에서 제공하는
주택 가격 데이터를 사용하였다.

- **Dataset:** House price prediction
- **Source:** Kaggle
- **URL:** [데이터셋 링크](https://www.kaggle.com/datasets/shree1992/housedata/data)


## 데이터 확인 및 전처리
- ### 결측치 확인
  이 데이터에는 결측치가 존재하지 않는다
- ### 이상치 처리
  유효한 데이터임에도 불구하고 주택 가격이 0인 경우가 존재한다는 것을 확인하였다<br>
  주택 가격 0에 대한 예측도 모델에 적용시켜 버리면 성능 측면에서 악영향이 나타날 수도 있다<br>
  물론 데이터의 유효성 측면에서는 데이터를 임의로 삭제하는 것에 주의가 필요하지만,<br>
  이 `basic`실습에서는 주택 가격이 0인 경우를 실제 주택 가격을 나타내지 않는 비정상적인 데이터로 분류하여<br>
  주택 가격이 0인 행은 삭제하는 방식이 적절하다고 판단하였다
  

## 데이터 나누기
- ### 독립.종속변수 설정
  - 독립 변수는 침실, 화장실, 주거 면적, 토지 면적, 층수, 해안가 유무, view 평점, 상태 평점, 지상층 면적, 지하층 면적, 지어진 연도 등으로 구성하였다<br>
    보수 연도는 0값도 포함하고 있으며, 이를 이상치로 판단할 경우 모델에 직접 넣기에는 적합하지 않을 수도 있다(그러므로 본 `basic`파일 에서는 `보수연도`를 독립변수에서 제외)
  - 종속 변수는 주택 가격으로
- ### Train/Test 데이터 분류
  `sklearn.model_selection` 모듈의 `train_test_split`을 이용하여
  데이터를 Train/Test로 약 7:3 비율로 나누었다.(`random_state=42`)
